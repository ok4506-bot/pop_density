# 배포 가이드 — 점검, GitHub 업로드, Cloudflare 발행

`github_upload` 폴더가 그대로 저장소 하나가 된다. Cloudflare 는 `wrangler.jsonc` 에 적힌 대로 **`site/` 폴더만** 웹에 올린다.

> git 명령은 직접 실행한다 (Windows VSCode 터미널 또는 PowerShell). `배포전_확인.bat` 은 git 을 건드리지 않는다.

## 0. 올리기 전 점검 (1분)

`github_upload\배포전_확인.bat` 을 더블클릭한다.

1. **STEP 1 점검** — 필수 파일, JSON, 5명 미만 칸, 파일 크기, 원자료·키 파일(.env, zip, MDIS) 섞임을 확인한다. `FAIL` 이 있으면 멈춘다.
2. **STEP 2 미리보기** — 브라우저가 `http://localhost:8000` 으로 열린다. 아래를 눈으로 확인한 뒤 검은 창을 닫는다.
   - 맨 위 나이별 순이동 그래프와 2023·2024·2025 전환
   - 생애단계 띠를 누르면 두 지도·그래프가 함께 바뀌는지
   - '사는 곳' 지도: 수도권 ↔ 토론토, 우세 생애단계, 시설 기호 켜고 끄기
   - '들어오고 나가는 곳' 지도: 들어오기 ↔ 나가기, 행정동 유입 LQ, 구를 눌렀을 때 오른쪽 구성
   - 수식(KaTeX)이 보이는지

노트북 `00. 수정\02_분석_실행.ipynb` 의 마지막 셀들도 같은 점검·미리보기를 한다.

## 1. GitHub 저장소

저장소는 `ok4506-bot/pop_density` (https://github.com/ok4506-bot/pop_density). 이름을 바꾸면 `site/assets/app.js` 맨 위 `REPO_URL` 도 같이 바꾼다.

## 2. 이 폴더를 올리기 (PowerShell)

```powershell
cd "<github_upload 폴더 경로>"     # 탐색기 주소창에서 복사
git init -b main
git add .
git status          # ← 여기서 .env, *.zip, work/, __pycache__ 가 없는지 꼭 확인
git commit -m "과제3 수정: 생애단계별 거주 LQ와 서울 인구이동 OD"
git remote add origin https://github.com/ok4506-bot/pop_density.git
git push -u origin main
```
- 처음 push 할 때 GitHub 로그인 창이 뜨면 로그인한다.
- 올라가는 용량은 약 4.5 MB 다.

## 3. Cloudflare 에 연결하기 (처음 한 번)

1. Cloudflare 대시보드 → **Workers & Pages → Create → Import a repository**
2. GitHub 계정을 연결하고 `pop_density` 저장소를 고른다.
3. 설정

   | 항목 | 값 |
   |---|---|
   | Project(Worker) name | `lifestage-capital-toronto` (`wrangler.jsonc` 의 `name` 과 같게) |
   | Production branch | `main` |
   | Build command | 비움 |
   | Deploy command | `npx wrangler deploy` (기본값) |
   | Root directory | 비움 |

4. **Deploy** → 1~2분 뒤 `https://lifestage-capital-toronto.<내 서브도메인>.workers.dev`

## 4. 발행 뒤

1. 주소를 `README.md` 의 "발행 주소"에 적고 Notion 과제3에 제출한다.
2. 고쳐서 다시 올릴 때:
   ```powershell
   python analysis\build_site.py    # 수치를 다시 만들 때만 (노트북으로 해도 됨)
   .\배포전_확인.bat
   git add .
   git commit -m "수정 내용"
   git push                         # push 하면 Cloudflare 가 자동으로 다시 발행
   ```

## 지도가 깨질 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 지도 바탕에 'API KEY REQUIRED' | CARTO 타일 (이번 판에서는 쓰지 않음) | 해당 없음 |
| 바탕이 회색 무늬 없이 비어 있음 | Esri·OSM 타일이 모두 막힌 망 | 시군구 경계·지명은 직접 그리므로 지도는 읽힌다. 다른 망에서 확인 |
| 지도·그래프가 아예 비어 있음 | `index.html` 을 직접 열었음 (file://) | `배포전_확인.bat` 으로 미리보기 |
| 지도는 있는데 색이 없음 | `site/data/*.json` 이 없음 | 노트북의 '웹 자료 내보내기' 셀 실행 |

카카오 지도 키는 필요 없다 (배경지도는 키 없는 타일만 사용).

## 자료 이용 조건

- MDIS 마이크로데이터 원자료는 저장소에 넣지 않는다 (`.gitignore` 가 `*.zip`, `work/`, `mdis_*.csv` 를 막음). 웹에는 시군구·행정동 집계값만 있고, 5명 미만 칸은 내보내지 않았다. 페이지와 README 에 출처와 "공식 입장이 아님" 문구를 적었다.
- SGIS 격자 값은 SGIS 통계지도에서 이미 공개되는 수준의 집계값이다.
